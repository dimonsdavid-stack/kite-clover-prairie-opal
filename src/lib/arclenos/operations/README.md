# Durable operations

Apply `migrations/0006_operations.sql` through the explicit database release command before invoking the scheduler. `DATABASE_URL` must target persistent PostgreSQL; the scheduler returns 503 on ephemeral PGLite. Configure HTTPS `BASE_RPC_URL`, optional `BASE_RPC_FALLBACK_URL`, and a server-only `CRON_SECRET` of at least 32 characters. Configure the hosting scheduler to invoke `/api/ops/tick` with `Authorization: Bearer <CRON_SECRET>` every 15 minutes. The endpoint itself is implemented; commissioning requires an actual external scheduler run and persisted attempts. Allow at least 90 seconds of serverless execution time.

Each invocation inserts deduplicated quarter-hour ingestion and RPC jobs and one daily audit job, then claims at most three jobs. Claim and attempt insertion execute in one SQL statement using row locks and SKIP LOCKED. Leases expire after timeout plus 15 seconds. Completion requires the exact lease token and an unexpired lease, preventing stale workers from finalizing recovered jobs. Timeouts abort fetches; retriable failures use capped exponential backoff. Lease exhaustion marks both job and attempt terminal. All presently executable tasks are read-only externally, and durable writes use source/job identities. Capital-bearing side effects must not be added without downstream idempotency and reconciliation.

Executable adapters: Base chain/block health with actual fallback request and persisted evidence; sourced DefiLlama Base protocol observations with per-source hourly deduplication; job/source/adapter audit. Three failures open adapter circuit breakers for five minutes. TVL remains TVL; no measured volume is fabricated. Upstream observation time is unknown and explicitly labeled retrieval time. Role specifications cover all 17 requested roles, but unsupported tasks produce BLOCKED attempts rather than invented execution evidence. No LLM is called and no capital is spent.

Exports for runtime integration: `rpcHealth(db, signal, endpoints)`, `configuredRpcEndpoints(env)`, `executeOperation(db, job, signal)`, `enqueue(db,kind,idempotencyKey,input)`, and `workOnce(db,handler)`. `operation_health` is the durable source for RPC adapter/circuit evidence. A successful fallback probe proves only this request used the fallback; consumers must use the same verified adapter selection before claiming general traffic failover.

Audits explicitly list uncovered contracts, wallets, payments, revenue, liquidity, treasury, frontend, dependencies, referrals and conversion. They return LIMITED on a clean supported scope, and FAILED when a supported invariant fails. They never average away failures. Production scheduling, mainnet manifest reconciliation and payment settlement reconciliation remain unverified until their respective providers are configured and tested.

Targeted test: `node --experimental-strip-types --test src/lib/arclenos/operations/queue.test.ts`. Tests run the real SQL against PGlite and cover idempotency, exclusive claims, lease fencing/recovery/exhaustion, retry backoff, adapter abort timeouts, explicit unsupported tasks, wrong-chain RPC failover, and honest audit scope.
